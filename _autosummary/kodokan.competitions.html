kodokan.competitions#

A calendar of upcoming judo competitions in one French département, and who may enter each.

The French judo federation (FFJDA) runs one agenda engine behind every regional and departmental site. Each site’s /evenement page embeds the whole national agenda as JSON in a hidden form field, so one GET gives every published event with its town, postcode, organiser, level and the extranet registration window; each event also has a detail page with the birth years, minimum belt and the rules of entry. The department’s committee additionally publishes a season forecast as a PDF, which is the only source for events more than four to six weeks ahead.

This module does the deterministic part of refreshing a calendar: fetch the agenda, select the area, fetch the detail pages and the forecast, and write a snapshot folder. Deciding who may enter each event (open, by qualification, a friendly interclub limited to named clubs) is reading prose rules, and is left to the person or agent doing the refresh: the kodokan-competitions skill is that procedure. The result is validated with validate_calendar() before it is published.

>>> html = '<input type="hidden" name="evenements" value=\'{"2026": {"11": [{"id_evenement": "1", "titre": "SHIREN", "codePostal": "13015", "date_debut": "1794096000", "date_fin": "1794096000", "libelleType": "COMPETITION", "proprietaire": "Comité X", "slug": "shiren"}]}}\' />'
>>> [e["titre"] for e in parse_agenda(html)]
['SHIREN']
>>> normalise(parse_agenda(html)[0])["date_start"]
'2026-11-08'

Nothing here names a club: the home club, the area and the output path are arguments (or a local config file the skill reads), so the module serves any club in any département.

Organisers whose events count even when held outside the area (regional league, the committee).
