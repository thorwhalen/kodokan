kodokan.tori_labels#

Hand-labelling of the tori heuristic (#49): sample demos, then score agreement.

recognize.tori_index decides which tracked judoka is tori (the thrower) from hip heights alone. There is no ground truth to validate it against, so the owner labels a stratified sample of demos by eye (in the web app’s owner-only labelling page) and this module closes the loop:

  • build_label_manifest() – pick ~60 demos (stratified over throw, source and the confident/abstain split) and emit, per demo, the two tracked people’s boxes over time, normalised to the frame so the page can outline them on the clip in two colours. The heuristic’s own answer is stored but the app never sends it to the labelling page.

  • agreement_report() – given the owner’s labels, the agreement with the heuristic (Wilson CI), split by confident/abstained, plus the “can’t tell” rate in each.

Command line:

python -m kodokan.tori_labels build manifest.json --n 60
python -m kodokan.tori_labels report manifest.json labels.jsonl

Needs the pose and segment stores (~/kodokan_data) for build only; report and the pure helpers need nothing but the two files.

kodokan.tori_labels.agreement_report(manifest, labels)[source]#

Agreement of tori_index with the owner’s labels.

A decided label (“A”/”B”) agrees when the named slot equals the heuristic’s. “Can’t tell” is excluded from agreement and reported as a rate, overall and per confident/abstained group – if abstentions are the genuinely ambiguous demos, their can’t-tell rate is higher.

kodokan.tori_labels.person_boxes(pose_seq, start_s, end_s, *, slots, min_conf=0.1, pad=0.08, max_frames=120)[source]#

Normalised boxes of the given person slots over a demo window.

Returns {"t": [seconds from window start], "boxes": [[ [x0,y0,x1,y1] | None per slot ] per frame]} with coordinates as fractions of the frame (so they scale to any rendition of the clip). Frames are thinned to at most max_frames; a slot with no usable joints in a frame is None.

Return type:

dict

kodokan.tori_labels.stratified_sample(entries, n=60, *, abstain_share=0.4, seed=0)[source]#

Pick n entries spread over throws and sources, with a guaranteed abstain share.

The abstained demos are the ones whose role label is in doubt, so they get at least abstain_share of the sample (fewer only if there are not that many). Within each half, strata are (throw, source) cells drawn round-robin from a seeded shuffle, so no throw or source dominates.

Return type:

list[dict]
