kodokan.store#

dol-backed stores for the pipeline’s artifacts (the analysis SSOT).

Two dict-like stores keyed by video_id:

  • pose_store() — video_id -> PoseSequence, each persisted as a tidy/long Parquet file (columns fidx, frame, t_sec, person, keypoint, x, y, conf) with sequence metadata (fps, dims, backend, source_url, frame indices) carried in the Parquet schema metadata. Tidy/long Parquet is the analysis SSOT — columnar, compressed, and pandas/polars/DuckDB-native (research §6).

  • segments_store() — video_id -> list[demo dicts] as JSON.

load_all_tidy() concatenates every clip’s table (adding a video_id column) into one DataFrame for cross-clip analysis.

kodokan.store.check_tidy_integrity(df, *, width=None, height=None, oob_margin_frac=0.05)[source]#

Row-level integrity checks on a tidy pose DataFrame.

Returns counts of anomalies (all should be 0 for a clean store):

  • n_duplicate_rows: rows sharing a (fidx, person, keypoint) key (each such triple must be unique per clip).

  • n_oob_xy: keypoints falling outside the frame by more than oob_margin_frac of its size (only checked when width/height are given; a small margin is tolerated since limbs can extend just past frame).

  • n_bad_conf: confidences outside [0, 1].

  • n_nan_xy: non-finite coordinates (occluded rows should have been dropped).

Return type:

dict
