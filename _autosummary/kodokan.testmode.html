kodokan.testmode#

Technique test mode: perform the technique the system names, get scored (#5).

TechniqueTest draws a technique at random from a focus pool (all the recognizer knows by default), names it, and grades the next performance on two things: how confidently the recognizer sees the target in it, and, when a reference for the target is given, how close it is to that reference (kodokan.coach.coach(), with its advice). TechniqueTest.push() runs the same loop on a live pose stream.

>>> import numpy as np
>>> from kodokan.recognizer import TechniqueRecognizer
>>> X = np.vstack([np.full((3, 4), c) + np.arange(3)[:, None] * 0.1 for c in (0.0, 3.0)])
>>> rec = TechniqueRecognizer(method="centroid").fit(X, ["o-goshi"] * 3 + ["uchi-mata"] * 3)
>>> test = TechniqueTest(rec, pool=["uchi-mata"], seed=1)
>>> test.next_prompt()
'uchi-mata'
>>> result = test.grade(np.full(4, 3.1))
>>> result.passed, result.score > 50
(True, True)

The test loop on a live stream: prompt, detect the throw, grade, prompt again.

push() takes one frame and returns (segment, result) for each throw that closed with it; after each graded throw the next technique is drawn (prompt). Detector options pass through.

A throw is graded once it has closed (close_after_s after it ends), so the performer should wait for the next prompt before the next throw; any motion the detector takes for a throw also uses up a prompt.

Parameters:

  • recognizer (TechniqueRecognizer) – a fitted TechniqueRecognizer.

  • pool (Iterable[str] | None) – the techniques to draw from (default: all the recognizer knows).

  • references (Mapping[str, dict] | None) – {technique: build_reference(...)}; techniques with one are also graded on closeness, with advice.

  • confidence_weight (float) – share of the score from the target’s confidence (the rest from closeness to the reference, when there is one).

  • seed (int | None) – or rng, for a reproducible sequence of prompts.
